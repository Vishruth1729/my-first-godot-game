# my-first-godot-game

A 2D platformer made with Godot where you play a knight who jumps across platforms, collects coins, and avoids slimes and long falls.

## Controls

- Move: Arrow keys + WASD

- Jump: Space bar

## Built With

- Godot 4.7.2
